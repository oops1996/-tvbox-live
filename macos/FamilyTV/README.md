# 家庭电视 macOS V3（0.3.3）

面向 Apple Silicon Mac（arm64），最低 macOS 13。

## 播放与原有功能

直播、OpenList / WebDAV、搜索、收藏、历史和设置均保留。播放层由 AVPlayer 更换为官方 VLCKit 3.7.3 / libVLC，完整框架随应用打包，无需安装 VLC 或 Homebrew。默认软件解码，网络缓冲 1500 毫秒；设置可调整，下次重试生效。播放器提供暂停、停止、重试、音量、全屏和点播进度控制。

直播和普通媒体播放都使用同一内核。WebDAV Basic 认证转换为仅在内存中的 URL 认证；历史不保存该认证 URL，历史重播仅对当前 WebDAV 同源、同目录的地址使用网盘认证。现有密码存储继续使用本机偏好设置，仓库不存储用户密码。

## 直播源导入与刷新

直播页顶部提供“导入 / 更换源”和“重新导入 / 刷新”，可查看刷新中、失败原因、最近成功时间、当前频道总数以及本次新增/移除数量。支持 UTF-8 TXT（频道名,地址；分组名,#genre#）和标准 M3U 列表。每次成功读取会以新列表完整替换旧列表；源中删掉的频道同步消失，空列表也会同步。刷新失败保留原有列表，不清空收藏、历史和网盘设置；已从源中移除的正在播放的直播频道会停止。较早请求不会覆盖新请求的结果。

直播请求使用无磁盘缓存会话并主动重新验证网络内容。现有 jsDelivr GitHub `@main` / `@master` 转发链接会读取对应的 GitHub 原文件，避免转发缓存落后；版本固定或带认证、查询参数的自定义地址保留原样。新安装默认使用 GitHub 原文件地址。设置页的刷新按钮使用同一逻辑，源地址与账号仍只存本机。

同一分组中同名频道合并成一个条目，不丢弃不同播放地址；完全相同的地址和请求头只保留一条线路。HD、4K 等名称不同的版本单独保留。播放区域提供线路选择和“切换线路”，显示已尝试的线路。错误、结束、连接异常回到已停止、直播 8 秒无数据、25 秒无画面或已播放后画面持续中断 20 秒时自动尝试尚未尝试的备用线路；一轮最多遍历所有线路一次，全部失败后停止，点击重试可开始新一轮。优先复用本次启动中成功出画面的线路。主动暂停或停止不会触发恢复。

默认直播 User-Agent 与电视配置中的 `okhttp/3.12.13` 一致，可在设置中修改；M3U `#EXTVLCOPT` 和地址后 `|User-Agent=...&Referer=...` 的线路专属请求头优先，传给 VLC 的 HLS 请求。收藏兼容原来的线路地址，新收藏按频道保存；自动切线不新增历史条目。连接状态区分尚未收到数据与已收到但无可解码画面，避免把所有黑屏都归为解码错误。网络缓冲仅对已经收到的数据起作用，无法替代成功连接。

直播页和设置提供“直播直连（绕过代理 / VPN）”，默认关闭。开启后，仅该应用的直播请求绑定 Wi-Fi / 以太网，不修改系统代理、VPN 或路由。回环地址中转会重写 HLS 跳转、主列表、分片、密钥和初始化片段的地址，保留线路 User-Agent、Referer 和字节范围；HTTPS 保持系统证书验证。中转仅监听 127.0.0.1，使用每次启动随机的路径标识，闲置连接超时回收；历史与收藏保存原始线路地址。点播及 WebDAV 不使用直播直连。开启或关闭时会重连当前直播。

## 播放窗口与操作

支持页面内嵌播放、可调整大小的独立窗口和仅显示播放器的 macOS 原生全屏。三种模式共用同一播放实例，切换保留当前位置、暂停状态、音量和倍速。关闭独立窗口或点击“嵌入”返回原页面；从嵌入模式进入全屏，退出后自动返回原页面。独立窗口可在“更多”菜单置顶，画面默认保持比例，也可选择填满并裁切。

点播提供 0.5×、0.75×、1×、1.25×、1.5×、1.75×、2×、2.5×、3×，前进/后退 10 秒、进度条、已播/总时长、音量和静音。直播保持正常速度，禁用倍速与点播跳转。播放画面旁显示从视频轨道读取的实际像素尺寸，不以片名中的“4K”作为画质依据。

快捷键：空格播放/暂停，左右方向键跳转 10 秒，上下方向键调音量，F 或双击视频全屏，Esc 退出全屏，M 静音，[ / ] 调整倍速，0 恢复正常速度。在搜索框等文字输入位置不会接管这些按键。

## 可更换的影视源

在“影视 → 管理 / 导入源”粘贴完整地址。可重新导入更新，也可编辑链接后导入另一份配置并切换站点；没有固定默认影视源。

支持标准 JSON / XML 采集接口及 TVBox 配置中的 type=0 / type=1 HTTP 接口。影视支持电影、电视剧、综艺、动漫、短剧、纪录片等类型，以及国产、香港、台湾、韩国、日本、美国、英国、法国、德国、泰国、印度等地区；可组合题材、年份和源内栏目筛选，并搜索、读取详情、切换线路和选集。分类根据接口名称、父分类与影片地区/年份/题材资料判断；资料不足时不猜测具体地区。欧美、日韩、港台等混合分类保留为宽泛地区。分类目录在 detail/videolist 不返回时额外读取 ac=list。筛选在源内相关栏目逐页读取，每次最多检查 6 页并去重，可继续加载后续匹配影片，显示已检查页数和是否到末尾。兼容 JSON5 注释和常见 JPEG 后附 base64 的配置封装；订阅 urls 列表以可选择导入的分支显示。

管理源支持勾选、全选、取消全选、批量删除。确认面板列出数量、名称和地址；仅删除选中的本机影视源配置，删除当前源会清空对应片库。收藏、历史、网盘资料和影视文件保留。处理中删除或切换源会使旧请求结果失效。

## 热度榜

提供爱奇艺公开热播榜的总榜、电视剧、电影、综艺、动漫、短剧；以官方实时热度和原始排名展示，标注官方更新时间、读取时间与平台范围，不将更新顺序当热度，不称为全网排名。可一键在当前影视源搜索榜单片名。读取公开页面数据，不执行网站脚本。手动刷新或停留 5 分钟后刷新；页面结构变化、断网或过期超过 48 小时的榜单显示错误及官方页面入口，不伪造数据。

此版本将用户指定的“家庭电视”图标纳入构建，后续安装保持同一图标。

TVBox 的 type=3 csp_ Android/JAR 插件、JS/Python 爬虫、加密脚本以及需网页解析的播放地址暂不支持。导入器会列出兼容情况，不把“读到配置”报告为“可播放”。饭太硬等链接是否可用取决于它实际返回的接口类型。应用不会自动执行第三方插件。

## 构建与验证

```bash
bash scripts/build-macos.sh
```

脚本固定下载官方 VLCKit 3.7.3 二进制包并验证 SHA-256，检查 arm64 切片与动态库路径，按从内到外的顺序临时签名，再生成保留权限/符号链接的 app ZIP 和含“应用程序”快捷方式的 DMG。

GitHub Actions 的 macos-14 arm64 runner 完成编译、签名检查、合成 H.264 MP4/HLS 视频帧解码和受损 TS 恢复、需要 Basic 认证的 WebDAV 与 HLS 子分片、直播缓存绕过与刷新同步、频道/线路去重、有限次数切线与历史收藏兼容、JSON/XML 分类目录补读、影片资料、组合筛选、跨页匹配、删除保存与异步请求防回写、热度榜解析与时效、分页/搜索/选集、DMG 和 ZIP 检查后，上传“家庭电视-macOS-arm64”产物。

测试视频为自动生成的单色渐变 H.264，没有第三方影视内容；测试认证随机生成，不使用用户密码。CI 使用内存视频回调验证解码帧，不依赖虚拟机的 GPU；GUI 画面和原生视频视图仍需真实 Mac 核验。可另运行 Tests/PlaybackSmoke.swift 检查 GUI。真实江西移动/NewTV 的播放仍需对应网络下实测；换内核无法恢复缺失 SPS/PPS、已损坏或被上游阻断的流。

直连传输另有无 GPU 的跳转、主列表/密钥/初始化片段/视频分片重写、分块响应、请求头、Range 和回环路径验证。在本次真实 Mac 测试中，江西卫视线路 1 持续显示 1920×1080 视频帧，湖南卫视线路 1 显示 3840×2160；这是当时网络与源的实测结果，不保证所有地址持续可用。

目前使用 ad-hoc 签名，没有 Developer ID 和公证，首次打开可能需要在 macOS“隐私与安全性”中允许打开。第三方授权与源代码位置见 THIRD_PARTY_NOTICES.md 和 LICENSE-VLCKit.txt。
